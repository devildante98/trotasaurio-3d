# 🦖 Trotasaurio 3D

Carrera infinita en 3D: un dinosaurio corre por el desierto saltando cactus y agachándose bajo los pterodáctilos. Cuanto más lejos llegas, más rápido corre.

## Cómo jugar

- **Espacio**, **↑** o un toque en la pantalla: saltar
- **↓**: agacharse (y en el aire, caer antes)
- **M**: activar o quitar el sonido · **P**: pausa

## Jugar en el navegador

Abre `index.html` en cualquier navegador moderno con WebGL. Si el repositorio tiene GitHub Pages activado, se puede jugar en
https://devildante98.github.io/trotasaurio-3d/

Hecho con [three.js](https://threejs.org/).
